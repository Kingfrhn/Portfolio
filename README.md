# Omar Farahan Molla — Senior QA Test Engineer Portfolio

A modern, high-performance **Next.js (App Router)** portfolio built to showcase 4.5+ years of QA game and application testing experience across Mobile, Console, PC, and Web platforms.

![Omar Farahan Molla Portfolio Banner](public/photo_omar.jpg)

---

## ⚡ Tech Stack & Architecture

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **UI & Styling**: Vanilla CSS Modules with custom dark QA IDE theme
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Space Grotesk, Inter, JetBrains Mono

---

## 🌟 Key Features

- **Live Status Indicator**: Header status dot & hero status bar (`RUN #0847 ▸ STATUS: STABLE ▸ 0 CRITICAL BUGS`).
- **Interactive Project Filtering**: Filter titles tested by King, Scopely, Bandai Namco, Microids, and Eidos Montreal by platform focus (`Mobile`, `Console`, `PC`, `Web`).
- **Sample Test Cases & Defect Inspector**: Interactive tabular suites with `PASS`/`FAIL` indicators and a **Jira Defect Inspector Modal** displaying repro steps, expected/actual output, and attached Logcat stack traces.
- **QA CLI Terminal Playground**: Interactive terminal where visitors can execute CLI commands (`status`, `skills`, `bugs`, `contact`, `download`).
- **Instant Resume Download**: Seamless 1-click download of `Omar_Farahan_Molla_Resume.pdf`.

## 🚀 Getting Started

### Local Development

1. **Clone repository**:
   ```bash
   git clone https://github.com/Kingfrhn/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run local dev server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.

4. **Production Build**:
   ```bash
   npm run build
   ```

## 🌐 Deployment Options

### 1. Vercel (Recommended)
1. Push your repository to GitHub.
2. Go to [Vercel](https://vercel.com) and import the repository.
3. Vercel will automatically detect Next.js and deploy your portfolio instantly with automatic HTTPS.

### 2. GitHub Pages
Next.js is configured for static export (`output: 'export'`). You can also deploy the production output directly to GitHub Pages.
